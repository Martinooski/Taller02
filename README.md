# Taller 02 - Pokemon (ICCI)

Este programa simula un juego de Pokémon por consola, donde el jugador puede capturar pokémons, armar su equipo, retar líderes de gimnasio y enfrentarse al Alto Mando para convertirse en campeón.

### Integrantes
* Martin Alvarado - 22.330.833-3 - [Martinooski]

### Estructura
Lógica centralizada en la clase Main.java, utilizando ArrayLists para el almacenamiento en memoria de la pokédex, el equipo, las medallas, los líderes y el Alto Mando. Las clases auxiliares Pokemon, Habitat, Lider y AltoMando modelan las entidades del juego. La clase Menu se encarga de mostrar los menús por consola y TablaTipos contiene la matriz de efectividades entre tipos.

### Instrucciones
1. IMPORTANTE: El programa requiere que existan los archivos "Alto Mando.txt", "Gimnasios.txt", "Habitats.txt", "Pokedex.txt" y "Registros.txt" en la misma carpeta raíz del proyecto para poder cargar la información.
